# Portfolio Case Study — Project 01

## LLM Response Quality Benchmark

### Human judgment for better AI

I designed an independent evaluation study to assess how well AI responses satisfy the same user request under a consistent rubric.

### The problem

AI responses can appear convincing while still being incomplete, poorly reasoned, factually incorrect, or non-compliant with the user's instructions.

### My approach

**Understand → Verify → Compare → Identify → Score → Explain → Improve**

I evaluated response candidates across six dimensions:

- Accuracy
- Reasoning
- Relevance
- Completeness
- Instruction following
- Clarity

Accuracy and reasoning receive higher weights because a polished answer is not useful if its core claims or logic are wrong.

### What I evaluated

The prompt set covers technology, sports, India and society, history, science, everyday knowledge, language and reasoning.
